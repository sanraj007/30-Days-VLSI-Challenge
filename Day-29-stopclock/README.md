🚀 Day 29: Digital Stopwatch with 7-Segment Display

🧠 Overview

This project implements a digital stopwatch using Verilog by combining timing, control logic, and display.

⚙️ Features

- Start / Stop control using FSM  
- Counter-based time tracking  
- Clock divider for slower timing  
- 7-segment display output  

🏗️ Modules Used

- Clock Divider  
- Control Unit (FSM)  
- Counter  
- 7-Segment Decoder  

🔁 Working

- Start signal enables counting  
- Counter increments based on slow clock  
- Output is displayed on 7-segment  
- Stop signal pauses the counter  
- Reset clears the system  

🧪 Testing

- Verified start and stop behavior  
- Observed counting sequence  
- Checked display output changes  

⚠️ Challenges

- Understanding clock division  
- Debugging timing-related issues  
- Ensuring proper synchronization  

🎯 What I learned

- Importance of clock in digital systems  
- Combining multiple modules into one system  
- Difference between logic and timing behavior  

🚀 Final Thought

This project helped me understand how real systems depend not just on logic, but also on timing and synchronization.
