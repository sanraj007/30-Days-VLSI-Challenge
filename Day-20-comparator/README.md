🚀 Day 20: 4-bit Comparator

🧠 Overview

A comparator is a combinational circuit used to compare two binary numbers.

⚙️ Concept

The comparator determines:
- A > B  
- A = B  
- A < B  

Only one output is active at a time.

🔍 Working

- If A > B → A_gt_B = 1  
- If A = B → A_eq_B = 1  
- If A < B → A_lt_B = 1
