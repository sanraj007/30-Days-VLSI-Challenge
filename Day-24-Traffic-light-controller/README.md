🚀 Day 24: Traffic Light Controller (FSM)

🧠 What I did

Today I implemented a simple traffic light controller using FSM (Finite State Machine).

⚙️ Concept

The system moves through different states to control the lights:

RED -> GREEN ->YELLOW ->RED

Each state represents a specific light.

🔍 How it works

- Starts from RED  
- Changes state on every clock cycle  
- Output depends on the current state  

🧪 Testing

- Created testbench  
- Ran simulation  
- Verified correct sequence of lights  

📁 Files

- `traffic_light.v`  
- `traffic_light_tb.v`  
- waveform  
- rtl  
- synthesis  

🎯 What I learned

- How FSM can be used in real-world systems  
- State transitions and output control  
- Designing behavior step by step  

🚀 Final thought

This was a simple design, but it helped me understand how FSM concepts are used in real applications like traffic systems.
