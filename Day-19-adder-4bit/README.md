🚀 Day 19: 4-bit Adder

🧠 Overview

A 4-bit adder is a combinational circuit used to add two 4-bit binary numbers.

⚙️ Concept

- Built using 4 full adders  
- Carry propagates from one stage to next  
- Produces sum and carry output  

🔍 Working

- Each full adder handles one bit  
- Carry output becomes next stage input  
- Final stage produces overall carry  

🛠 Implementation

- Verilog HDL  
- Structural modeling  
- Xilinx Vivado  

🧪 Verification

- Testbench created  
- Multiple input cases tested  
- Carry propagation observed  
- Output verified  

📁 Files

- `full_adder.v`  
- `adder_4bit.v`  
- `adder_4bit_tb.v`  
- waveform  
- rtl  
- synthesis  

🎯 Learning

- Multi-bit arithmetic design  
- Carry propagation concept  
- Structural modeling  

🚀 Insight

This design demonstrates how simple components can be combined to perform complex operations, forming the foundation of arithmetic logic units (ALUs).
