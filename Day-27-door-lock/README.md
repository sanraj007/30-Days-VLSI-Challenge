🚀 Day 27: Digital Door Lock System

🧠 What I did

Built a password-based door lock system using FSM.

💡 Idea

The system checks a sequence (1011) and:
- Unlocks if correct  
- Counts wrong attempts  
- Triggers alarm after 3 wrong inputs  

 ⚠️ What I struggled with

- Understanding how FSM reads input with clock  
- Debugging why output was always 0  
- Fixing input timing in testbench  

🧪 Testing

- Tried wrong sequences → alarm triggered  
- Tried correct sequence → unlock worked  
- Verified behavior using waveform  

🎯 What I learned

- FSM depends heavily on timing  
- Input must align with clock  
- Debugging is as important as coding  

🚀 Final thought

This project taught me more through debugging than implementation.
