🚀 Day 23: FSM (Sequence Detector)

🧠 What I did

Today I worked on a Finite State Machine (FSM) to detect the sequence "101".

⚙️ Concept

- System moves through states  
- Based on input and clock  
- Output depends on state  

🔍 States

- S0 → Start  
- S1 → Got '1'  
- S2 → Got '10'  
- S3 → Got '101' (output = 1)  

🧪 Testing

- Applied input sequence  
- Observed state transitions  
- Verified detection in waveform  

📁 Files

- `FSM_101.v`  
- `FSM_101_tb.v`  
- waveform  
- rtl  
- synthesis  

🎯 What I learned

- How state machines work  
- State transitions  
- Designing behavior, not just logic  

🚀 Final thought

This felt like moving from simple circuits to designing systems that actually behave over time.
