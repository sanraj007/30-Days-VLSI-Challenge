🚀 Day 16: 4-bit Register

🧠 Overview

A register is a group of flip-flops used to store multiple bits of data.

⚙️ Concept

- 4-bit register = 4 D Flip-Flops  
- Stores 4-bit input data  
- Updates on clock edge  

🔍 Working

- On clock edge → Q takes value of D  
- Reset clears stored value  

🛠 Implementation

- Verilog HDL  
- Xilinx Vivado  
- Behavioral modeling
