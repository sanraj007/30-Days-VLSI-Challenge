🚀 Day 17: Shift Register

🧠 Overview

A shift register is a sequential circuit that shifts data from one position to another on each clock cycle.

⚙️ Concept
- Data enters serially  
- Bits shift on every clock  
- Output updates continuously  

🔍 Working
At every clock edge:
- Existing bits shift left  
- New bit enters from input  

🛠 Implementation
- Verilog HDL  
- Xilinx Vivado  
- Sequential logic design
